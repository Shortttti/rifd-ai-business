# رَشّة — وكيل محتوى لعمولات أدوات الخَبز

مشروع عربي ينشر دليلًا معلوماتيًا واحدًا يوميًا على GitHub Pages. يختار منتجًا من `products.json` لديه رابط عمولة HTTPS، ويطلب من Gemini كتابة مسودة مستندة إلى المعلومات الموجودة فقط، ثم يضيفها إلى `posts.json`. لا يشتري مخزونًا، ولا يدير حساب متجر، ولا ينفذ مدفوعات أو تداولًا.

## الموجود الآن

- موقع عربي متجاوب يعرض الأدوات والأدلة المنشورة.
- إشارة واضحة إذا كانت روابط العمولة غير مفعّلة.
- مهمة GitHub Actions مجدولة يوميًا، مع زر تشغيل يدوي.
- مولّد أدلة عبر Gemini Interactions API؛ لا يضع مفتاح API في ملفات الموقع.
- لا يختلق أسعارًا أو مراجعات شخصية؛ يكتب اعتمادًا على وصف المنتج وحقول التحقق.

## شرط بدء النشر الآلي

تحتاجين إلى إكمال هذين الأمرين مرة واحدة بنفسك لأن الحسابات والموافقة والمفاتيح لا يمكن إنشاؤها باسمك:

1. سجّلي في برنامج عمولة متجر متاح لك وانتظري الموافقة. شروط القبول وعدد المبيعات المطلوبة تختلف وتتغير حسب البرنامج. لا توجد عمولات مضمونة.
2. أضيفي `GEMINI_API_KEY` إلى **Settings → Secrets and variables → Actions → New repository secret**. احصلي على المفتاح من Google AI Studio وراجعي حدود الخطة المجانية قبل الاستخدام.
3. بعد الموافقة، عدّلي `products.json`: ضعي رابط العمولة الفعلي في `affiliateUrl` لكل منتج، واستبدلي الوصف التجريبي ببيانات المنتج الدقيقة. لا تضعي أسرارًا في هذا الملف.
4. تأكدي أن **Settings → Pages** تشير إلى فرع `main` ومجلد `/ (root)`، وأن Actions مسموح لها بالعمل. الرنّ اليومي يظهر في تبويب **Actions**، والموقع يعرض الأدلة المنشورة.

بعدها يولّد الموقع دليلًا يوميًا تلقائيًا. يمكن تشغيله يدويًا من **Actions → Daily affiliate content → Run workflow**. قد تستغرق تغييرات Pages بضع دقائق حتى تظهر.

## لا تشاركي المفتاح

المستودع عام؛ ملفات الموقع والمنتجات والأدلة عامة. احفظي مفتاح Gemini فقط في GitHub Actions Secrets، ولا تكتبيه في رسالة أو ملف عام. إذا انكشف مفتاح، ألغيه وأنشئي غيره فورًا.

## حدود المشروع

- النسخة الحالية لا تتصل بحساب متجر عمولة ولا تسجل المبيعات؛ برنامج المتجر هو من يتتبع الإحالات والعمولات.
- لا يوجد جمهور أو زيارات مضمونة، ولا دخل متوقع مضمون. المحتوى الآلي وحده لا يضمن البيع.
- يكتب المحرك مسودات معلوماتية ولا يثبت الأسعار أو المخزون. راجعي أي معلومة أو شرط نشر يطلبه برنامج العمولة قبل تفعيل الروابط.
- الموقع لا يشتري منتجات لإعادة بيعها، ولا يستخدم أموالًا، ولا يتداول أصولًا مالية.
- النشر اليومي عبر GitHub Actions في مستودع عام متاح حاليًا ضمن استخدام GitHub Actions المجاني القياسي للمستودعات العامة. حدود خدمات الذكاء الاصطناعي تتبع حساب Google وخطته، وقد تتغير.

## التعديل

- المنتجات وروابطها: `products.json`
- الأدلة المنشورة: `posts.json`
- تعليمات التوليد: `scripts/generate-post.mjs`
- موعد التوليد: `.github/workflows/daily-content.yml`
