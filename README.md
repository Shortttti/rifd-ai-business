# Ticket Trader Agent

بوت تحدّي لإدارة قرارات شراء/إعادة بيع التذاكر في بيئة Webook-like. هذا المستودع يحتوي حاليًا على **محرك قرار واختبارات ووضع محاكاة**؛ لا يتصل بمنصة حقيقية ولا ينفّذ معاملات.

## ابدئي من هنا

اقرئي [تعليمات بوت التذاكر](ticket-bot/README.md). شغّلي المحاكاة أولًا، ثم يُضاف موصل المنصة المصرّح به بعد معرفة طريقة واجهتها التقنية. لا تضعي بيانات البطاقة أو كلمات المرور أو مفاتيح الربط في مستودع GitHub العام.
