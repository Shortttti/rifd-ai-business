حالة الربط

الموقع منشور. التشغيل التجاري يحتاج تفعيلًا واحدًا.

قبل ربط حساب العمولة، لا توجد روابط شراء ولا أرباح. ملف التعليمات داخل GitHub يحدد الخطوات والمفاتيح المطلوبة. لا تضعي أي مفتاح سري داخل ملفات الموقع العامة.
